# Evaluation framework

Score each serious candidate 1–10 on each criterion. Total 90. Be honest; document why low.

1. **PAIN** — how painful/frequent is the problem? (recurring > one-off; expensive > annoying)
2. **WILLINGNESS TO PAY** — credible economic reason to pay; existing paid competitors are evidence.
3. **REACHABILITY** — can we get the first 20 users ourselves, this month?
4. **BUILD SPEED** — meaningful value in ≤2 solo days?
5. **OPERATING COST** — near-zero (static/client-side) > small server > AI per-request?
6. **COMPETITION GAP** — narrow underserved angle exists? (competition is fine; commodity is not)
7. **RETENTION** — recurring need so users return without re-acquisition?
8. **FOUNDER FIT** — one dev can build, maintain, and sell it?
9. **DISTRIBUTION FIT** — realistic acquisition path without ad spend?

Bar to build: ≥60 total, no criterion <5, WTP ≥7. Otherwise park it in CANDIDATES.md and move on.
