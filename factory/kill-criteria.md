# Kill criteria template

Write these BEFORE launch. Default thresholds (adjust per product, don't skip):

- 30 targeted community messages/posts → <5 meaningful replies → reconsider positioning or kill.
- 100 landing visitors → <10 conversions to try-free → message/positioning problem; retest once, then kill.
- 10 people tried it → 0 would pay asking price → reprice once; still 0 → kill.
- Users acknowledge pain but won't pay because current workaround is "good enough" → kill.
- Support burden requires owner labor per customer → automate or kill.
- Operating cost per user > 30% of price at expected scale → re-architect or kill.
- 6 weeks with no revenue signal of any kind → kill.

Do not protect a product because code exists. Sunk cost is not a signal.
